pianoroll.js

Edit an ABC score on a grid. No dependencies, no build step, nothing downloaded.

Lyrics

Press Fit melody to the lyrics and the vocal line is reshaped so that the number of notes matches the number of syllables — surplus notes merge, long ones split, and the contour survives.

ABC — this is the score, kept in sync

Parsing and rebuilding is lossless: PR.build(PR.parse(abc)) round-trips real model output without dropping ties, accidentals or chord marks.
